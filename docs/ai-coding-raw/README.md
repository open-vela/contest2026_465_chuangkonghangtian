# logs/ —— AI Coding 日志

本目录是本队按大赛《参赛代码提交指南》要求，**主动导出并选定**后提交的 AI Coding 日志。

官方原文：

> 「AI Coding 日志：与 AI 工具的对话会自动记录到**本机 staging**（不会自动上传），
> 需由你**主动导出/打包选定会话**到仓内 `logs/` 目录后一并提交。」
>
> 「AI Coding 日志由插件自动写入仓内 logs/ 目录，**请勿手动删改**。」

因此本目录中的内容**未经任何内容改写**：仅做了「解压 + 格式转换 + 去重 + 选定会话」，
每条记录都可与本机原始会话逐条对上。

## 内容

| 文件 | 说明 |
|---|---|
| `AI_Coding_日志.md` | 可读转录：用户提问 + AI 回复 + 推理摘要 + 工具调用行（5.8 MB） |
| `sessions/*.jsonl` | 机器可读完整记录：含每次工具调用与命令输出（11 个会话 / 14.4 MB） |
| `_session_index.json` | 本机全部 30 个会话的清单、收录/排除理由与用量统计 |
| `_session_topics.txt` | 会话标题与提问索引 |
| `会话记录_火箭地面站_0907-0912.md` | 关键开发周期的完整会话留档 |
| `README.md` | 本文件 |

## 选定口径

本机共 30 个 AI 工具会话，**选定其中 11 个与本作品直接相关**的会话提交：

- **纳入（11 个）**：ESP32-S3 传感器底板设计、无源蜂鸣器测试、SF32LB52 触摸屏调试、
  openvela/NuttX 串口设备确定、开发环境搭建与板级驱动、地面站固件主体开发、
  遥测/雷达/网页大屏与 SD 驱动排查等。
- **排除（19 个）**：机械建模、个人事务等与作品无关的内容；另有 2 个与前者重复的
  并行会话已去重。
  排除理由逐条记录在 `_session_index.json` 的 `note` 字段中。

## 处理方式（可追溯）

DSH 的 `session.jsonl.zstd` 是**多帧 zstd**，整体解压只能得到第一帧，必须在魔数
`28 B5 2F FD` 处切帧后逐帧解压。抽取链路见 `../source/tools/ai_logs/`：

```
zst_frames.js / scan_sessions.js   切帧解压、扫描全部会话
full_logs.js                       富抽取：提问 + 回复 + 推理摘要 + 工具调用 + 工具结果
gen_readable_log.js                生成可读 AI_Coding_日志.md 与 _session_topics.txt
token_stats.js                     统计模型调用次数与 token 用量（报告 3.6 数据来源）
```

抽取时丢弃纯重复的流式分片（`*chunks`，约占原始体积 55%），仅对超长工具输出按固定上限
截断，并在记录中标注 `truncated` / `fullLength`，因此是**可追溯的忠实记录**。
